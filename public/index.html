ℹ️ How to use this app
  1. Choose Existing machine (pick a machine code, its sensor values load automatically) or New machine (type a new code and enter the values).
  2. Change any sensor value if you want, then press Predict.
  3. You get a risk level, the failure probability and the remaining useful life (RUL) in days. Every prediction is saved, so the trend and history below keep growing.
